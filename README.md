# SPL – Structured Programming Language

## Overview
This repository contains a collection of C programming practice problems and solutions completed as part of the Structured Programming Language (SPL) course. It serves as a record of programming exercises and practical implementations of fundamental concepts in C.

## Topics Covered
- Basic Programming Concepts
- Variables and Data Types
- Operators and Expressions
- Conditional Statements
- Loops and Iterations
- Pattern Printing
- One-Dimensional and Two-Dimensional Arrays
- String Manipulation
- Functions
- Recursion
- Pointers
- Problem Solving

## Technologies Used
- **Programming Language:** C
- **Code Editor:** Visual Studio Code
- **Compiler:** GCC

## Repository Organization
Practice problems are organized into folders based on their respective topics for better accessibility and maintainability.

## Objectives
- Develop a strong foundation in C programming.
- Improve logical reasoning and problem-solving abilities.
- Apply programming concepts through practical exercises.
- Maintain a structured collection of coursework and practice solutions.
